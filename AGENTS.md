# 🤖 FRONTEND AI CODING INSTRUCTIONS (PAYPRO V.6)

> [!IMPORTANT]
> **MANDATORY SPEC-KIT FIRST POLICY:**
> Sebelum membuat atau merombak UI/UX frontend, AI **WAJIB** membaca dan mematuhi dokumen di `spec-kit/` sebagai acuan utama.

---

## 📌 Checklist Wajib Frontend Developer / AI:
1. **Reusable Component Uniformity:** Wajib 100% menggunakan `<DataTable />`, `<CustomModal />`, `<CustomSnackbar />`, `<CustomConfirmDialog />`, dan `<SearchableSelect />` dari `src/components/Common/`.
2. **Collapsible Minimal Linear:** Semua tabel data yang lebar wajib menerapkan 7-9 kolom utama kompak + collapsible sub-row 3 kolom.
3. **No Legacy UI Copy:** Tampilan lama yang jadul/kuno dilarang disalin; hanya gunakan nama kolom dan flow bisnisnya.
4. **Theme Tokens:** Gunakan token theme MUI (`primary.main`, `background.paper`, `divider`).
5. **Build Verification:** Wajib verifikasi dengan `npm run build` (harus 0 error).
